CAIS: AI Онлайн Радио Станция

Описание

Интелигентна онлайн радио станция, която генерира инструментална музика в реално време чрез използване на AI технологии. Системата поддържа множество канали с независими конфигурации и осигурява безпроблемно слушане с гладко превключване между песни.

Ключови Особености

  • Мулти-канална архитектура с независими конфигурации за всеки канал
  • Генерация на музика в реално време чрез AI API (анализ на текст/видео) → AI (генерация на аудио)
  • Реално комуникиране (чат, аудио стрийминг, актуализации на интерфейса)
  • Разширена система за опашки с ограничение на заявките
  • Режим "сън" за канали без слушатели за оптимизация на ресурсите
  • Аудио визуализатор с динамични ленти, подобрени цветове и ефект "bloom"
  • Различни типове заявки: чат, бърз избор на стил, разширени заявки, URL на видео
  • Автоматична генерация на музика когато няма потребителски заявки
  • "Топла опашка" за незабавно пускане по време на стартиране

Техническа Архитектура

Системата е базирана на ASP.NET Core MVC с SignalR hub и специфични услуги за всеки канал:

  • ChannelManagerService - оркестрира каналите
  • RadioService - управлява логиката на канала
  • GenerationDispatcherService - обработва заявките за генерация
  • ComfyUIService - комуникира с ComfyUI API
  • PlaybackService - управлява аудио стрийминга
